# Material Symbols icon font

- Family: Material Symbols Outlined
- Source: Google Fonts CSS API, restricted to the 35 icon names used by this site
- Local subset: `MaterialSymbolsOutlined-subset.ttf`
- License: Apache License 2.0, bundled as `MaterialSymbols-LICENSE.txt`

This is an icon font, not a text typeface. It is hosted locally so the site does not depend on Google Fonts during page loading.
