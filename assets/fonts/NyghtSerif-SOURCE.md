# Nyght Serif font source

- Family: Nyght Serif v0.5
- Designer: Maksym Kobuzan
- Source supplied by the project owner: `/Users/mac/Downloads/nyght-serif-main/`
- Upstream: https://github.com/maxkobuzan/nyght-serif
- License: SIL Open Font License 1.1
- Bundled web files: Regular, Regular Italic, and Bold WOFF2
- Homepage critical subset: `NyghtSerif-home-critical.woff2`

The homepage also uses `Spectral-home-critical.woff2`, a reduced first-view subset of the bundled Spectral Regular font. Both critical subsets retain the homepage's Latin text and punctuation while the full fonts remain available on inner pages.

The full SIL OFL 1.1 text is bundled as `NyghtSerif-OFL.txt`.
